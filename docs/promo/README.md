# Promo

Release artwork and the design language behind it.

`inhabited-geometry.md` is the visual philosophy: the cold apparatus of a
drafting sheet — module grid, dimension line, revision block — used to
describe something warm. Every release card is drawn from it, so the set
stays recognisably one hand rather than a folder of unrelated pictures.

The cards are built from the product's own materials: the dark palette
from `web/src/styles.css` and the three typefaces the interface itself
loads (Unbounded, Golos Text, JetBrains Mono). What is drawn is true —
the board on `family-hub-v1.1.0.png` is the real eight-unit grid with the
real default arrangement, resting on the shared baseline the packer
computes.

1600×900 at 2× (3200×1800): the ratio a timeline shows without cropping.
